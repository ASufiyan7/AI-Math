# 🎨 AI-Powered Math Solver

An interactive web application that recognizes and solves handwritten mathematical equations. Just draw a problem on the canvas, and let the AI do the rest!

---

## ✨ Core Features

* **✍️ Interactive Drawing Canvas:** A simple and intuitive canvas to draw any mathematical expression.
* **🤖 Real-Time AI Recognition:** Uses Google's powerful Gemini Vision model to accurately interpret handwriting.
* **🧮 Handles Complex Equations:** Capable of solving multi-step equations, algebra, and more.
* **✨ Beautiful LaTeX Output:** Solutions are rendered beautifully using MathJax for a professional, academic look.
* **🖐️ Draggable Results:** Reposition the rendered solution anywhere on the canvas for better visibility.

---
